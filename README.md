## 七、問題回答

**1. 為什麼文字人數要轉成數字？**

因為 Python 的文字不能直接拿來做除法計算，所以要使用 int() 把文字轉成整數，才能正確計算每個人需要付多少錢

**2. 為什麼先扣折價券再計算服務費，總額會變成 1,210 元？**

因為原本餐費是 1,200 元，先扣掉 100 元折價券後，剩下 1,100 元，再加上 10% 的服務費 110 元，最後總額就是 1,210 元

原本先計算服務費再扣折價券，總額則是 1,220 元，所以計算順序不同，結果也會不同
